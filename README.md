# routeleaf

Route structured JSON leaf payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/routeleaf/

## Install / run

```bash
git clone https://github.com/theworker02/routeleaf.git
cd routeleaf
node src/cli.js
node --test
```
